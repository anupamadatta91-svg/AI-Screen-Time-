# Lecturer Demo Checklist

## Before the demo

- Build and install the application.
- Grant Usage Access.
- Use several apps for a few minutes so usage data exists.
- Set the daily limit to 30 minutes for an easy demonstration.

## Demo sequence

1. Open AI Screen Time.
2. Explain why Usage Access is required.
3. Show today's total usage.
4. Show the list of most-used apps.
5. Change the daily limit.
6. Show the progress indicator.
7. Explain the AI score.
8. Explain why the score is interpretable.
9. Demonstrate the recommendation.
10. Explain future alert/background monitoring.

## Suggested presentation sentence

"This prototype combines Android usage analytics with an explainable AI scoring layer. Instead of only showing raw screen-time numbers, it transforms usage behavior into a risk score and actionable recommendations."
